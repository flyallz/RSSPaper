# v1.5.0：期刊标签与网页摘要

- 接入 easyScholar 期刊 / 会议等级查询。应用设置新增独立密钥、启用开关、显示体系选择和接口测试。默认关闭；用户在卡片核对正式刊名后按需查询。
- 解析官方与自定义目录标签；区分体系并标明 easyScholar 来源。未提供年度时不推定年份；详情列出全部结果，卡片按所选体系展示并可悬停查看。
- 等级按正式刊名缓存，支持限速、更新、取消与安全关闭。失败不冒充无等级；更换密钥清理账户相关缓存。arXiv 分类和用户来源别名不自动作为期刊查询名称。
- 来源编辑新增正式刊名 / 会议名字段，Crossref 与已知出版商 RSS 可读取正式刊名。刷新保留用户确认的名称，已有订阅与 schema 1 数据兼容。
- 增加 ScienceDirect / 知网网页摘要适配器，与 Crossref 构成回退链。只读取明确摘要区域或 citation_abstract；核对原始题名与可用 DOI，排除 Highlights、普通网页简介和明显截断内容。
- 增加“导入摘要”：支持浏览器保存的论文 HTML，以及包含摘要的 CSL / Zotero JSON。匹配当前论文后更新，不扫描浏览器 Cookie 或整个 Zotero 文库。文献 JSON 不承诺摘要完整性，保持明确标记。
- 替换摘要后使用对应新内容的翻译缓存，保留阅读位置与筛选；用户导入可取消该论文正在进行的摘要查询，防止迟到结果覆盖导入。
- Mac 使用独立钥匙串账户，Windows 使用独立 DPAPI 文件，避免 easyScholar 密钥覆盖翻译密钥。设置保存失败时尝试还原已修改的密钥。
- 卡片动作分行排列，设置表单可滚动。两端验证小窗口和 100% / 150% / 200% 显示缩放。

## 已验证与边界

本地 126 项共享测试，125 通过、1 项另一平台专属测试跳过；静态与格式检查通过。覆盖身份不一致、摘要片段、元数据回退、JSON 导入、API 响应无效、密钥隐私、独立存储和回滚、缓存期限、过期结果、网络取消与父窗口关闭，以及缩放布局。

C&E RSS 的正式刊名解析实测成功。当前网络直接访问 ScienceDirect 详情页被拒绝，因此不宣称每篇自动摘要获取成功；知网校园登录环境也未验证。没有使用用户有效 easyScholar 密钥，真实账户权限及配额需在应用中测试。已实现接口接入和模拟响应回归，不等于已经通过真实账户验收。

出版社网页可能改版、动态加载或要求浏览器验证；保存网页也必须实际包含摘要。一般 RSS 和第三方记录没有提供的内容不会由大模型补造。APA 引用仍为纯文本参考文献条目。完整使用步骤见《期刊标签与摘要导入说明》。
