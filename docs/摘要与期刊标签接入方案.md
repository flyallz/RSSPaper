# 摘要与期刊标签接入方案

## 已核实的实现依据

核对日期：2026-09-29。

- Zotero Connector 使用网页适配器（translator）和嵌入元数据，而不是只读 RSS。官方说明：<https://www.zotero.org/support/dev/translators>。
- ScienceDirect 的适配器在导出记录缺少摘要时调用 `getAbstract(doc)` 从网页补取：<https://github.com/zotero/translators/blob/master/ScienceDirect.js>。
- 知网也有独立网页适配器，其测试包含完整及截断摘要，说明网页访问也不能保证所有记录完整：<https://github.com/zotero/translators/blob/master/CNKI.js>。
- Connector 支持机构代理识别：<https://www.zotero.org/support/connector>。浏览器能访问的页面不一定可由当前 Python HTTP 客户端访问；后者没有浏览器会话和学校代理身份。
- 用户所指插件为 Ethereal Style，对应服务名是 easyScholar。期刊等级字段映射实现：<https://github.com/MuiseDestiny/zotero-style/blob/master/src/modules/easyscholar.ts>。
- 官方期刊等级接口入口 `https://www.easyscholar.cc/open/getPublicationRank` 在不提供密钥时返回“密钥不能为空”。本次未使用用户密钥，尚未验证有效密钥下的响应结构、账户权限及数据年度。
- 接口控制台文档：<https://www.easyscholar.cc/console/query>；本次自动读取超时。插件项目的问题报告提到每秒最多 2 次请求，正式实现前必须以官方当前文档为准，不能把报告当作已验证约束。

## 实施顺序

1. 扩展论文元数据：真实期刊名称、ISSN / eISSN、会议名称、文献类型；与用户可修改的来源别名分开。`CE` 或 `AI` 不能直接用作期刊查询名称。
2. 摘要补全增加提供器链：现有 RSS → DOI 登记数据 → ScienceDirect / 知网公开论文页面。按 DOI 或原始文献标识核对身份；通用页面元数据可以尝试，但不能将页面简介或搜索片段标成完整摘要。
3. 公开页面失败时给出明确原因。优先支持用户主动导入 Zotero 导出的带摘要记录，按 DOI / 原文标识合并；验证格式中是否实际携带摘要。机构登录页面另做浏览器辅助采集，不复制用户的整个浏览器 Cookie 库，不把学校账号交给服务端。
4. 单独接入 easyScholar 等级提供器。设置界面提供启用开关、密钥配置、显示体系选择及测试；密钥与翻译密钥分开保存在本机安全存储。没有密钥时不影响 RSS、摘要和引用。
5. 用已确认的期刊 / 会议实体查询，按实体去重、排队、全局限速并缓存；临时错误不冒充“无等级”。接口限速、密钥参数、授权范围和缓存期限以官方文档与账户权限为准。
6. 卡片在期刊名旁显示所选标签，如 `JCR Q1`、`CSSCI`、`CCF A`。详情中列出体系、年度（接口未提供时明确“年度未知”）、来源和获取时间。预印本不能继承未经确认的期刊等级；会议按会议目录处理。

## 维护边界

- 来源订阅、摘要获取、引用格式化、等级查询各自独立。界面只展示标准化结果，业务服务负责缓存和生命周期，适配器负责第三方格式。
- 等级按刊物缓存，论文只关联刊物实体。缓存包含数据来源、数据集标识、版本 / 年度、获取时间和结果状态，不能只保存一个不明含义的“一区”。
- 摘要缓存保留出处、完整性状态和获取时间；不以文本更长作为完整性证明。新摘要替换后，使旧译文失效。
- 网页结构会变化，每个适配器使用脱敏固定样本测试，并设置清晰失败状态。借鉴 Zotero 代码前核实相应开源许可与署名要求。
- Windows / Mac 同步验证：缺失密钥、接口超时、限速、重复期刊、别名、学科切换、旧缓存、摘要片段及身份不一致、后台取消与关闭、不同屏幕缩放。

## 首轮验收

用真实样本分别验证 ScienceDirect 与知网：RSS 片段 → 论文公开页面摘要 → 校园网登录页面。逐项记录可获取性，明确哪些场景需要浏览器辅助，不承诺全站或全部论文支持。等级功能用用户在应用中填写的密钥测试几本中英文期刊和一项会议，确认字段与年度后再开放默认展示。
