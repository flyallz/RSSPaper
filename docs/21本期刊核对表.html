使用与维护

Inoreader：设置 → Import, Export, Backup → OPML Import。Zotero：Add Library → New Feed → From OPML。文件中的标题带“必读／选读”前缀，分组在 Zotero 中的呈现取决于版本；文章需另行保存到文献库。参见 Zotero 官方说明。

IEEE TLT 通过官方 Content Alerts 补齐。中文刊 CNKI RSS 每次返回最近 20 条，可能晚于官网更新；每周检查新增条目，每月对照官网目录补漏。用 DOI 或规范化原文链接去重。RSS 卷期日期、上线日期、首次发现日期可能不同，不能把所有导入条目都算成本周新论文。

OpenAlex 是 JSON 数据接口，不是 RSS。英文刊可作补查；匹配到的 3 本中文刊记录陈旧，其他 8 本 ISSN 查询返回 404，均不能直接补齐最新中文论文。若日后自动化，应保留首次发现时间、回看近 30 天以捕捉延迟收录，并使用私人 API key；不要把密钥放进公开 OPML。

方法：核对原始培养方案；官方／主办方页面与可靠目录交叉检查；HTTP＋XML＋条目身份检查；OpenAlex ISSN 单实体查询及论文查询。一次实测不是长期稳定性保证。搜索未找到入口记作“未发现／未核实”，不等于断言不存在。培养方案中的书籍和手册未纳入。
