# v1.4.4：翻译完整性与后台任务

- 标题和摘要使用不同输出预算；长摘要按段落或句子分段发送。检测模型的输出截断标志，有限重试后仍不完整则明确失败，不缓存任何部分结果。
- 旧版本的摘要译文可能曾被截断，因此改用新摘要缓存键；原标题译文、订阅和其他历史缓存仍保留。
- 原文摘要、摘要译文分别展开或收起，并可复制完整内容；长译题也可以展开和复制。
- 自动刷新、加载更多、保存设置统一保留正在阅读的论文与展开状态。阅读状态按学科和筛选条件隔离，并限制内存保存数量。
- 翻译最多同时进行 2 项，最多接收 20 项（包括进行中和排队）；重复请求不入队，显示任务数量与排队状态。
- 增加“取消后台任务”，清除排队任务并停止后续请求。已经发出的网络请求等待返回或超时，取消后的结果不会显示或保存。取消来源刷新后，在下一个刷新间隔前不自动重启；仍可手动刷新。
- 关闭主窗口会取消任务并在工作线程退出后自动关闭；设置中的接口测试也支持取消后自动退出。不会强制终止网络线程。
- 翻译失败也检查原学科、内容和模型；过期失败不再修改当前卡片或弹出打断阅读的对话框。有效失败会在状态栏与按钮提示中说明原因，可重试。
- 混合语言按中文与拉丁字母占比判断，避免英文摘要中的个别中文姓名改变翻译方向。
- 主窗口适配 820×500 小尺寸；设置与来源表单支持滚动，窗口初始尺寸遵循可用屏幕大小。
- Windows 字体加入 Microsoft YaHei UI；自动验证 100%、150%、200% 显示缩放下的长卡片和来源/设置表单。真实设备上的字体渲染仍可能有差异。

## 使用边界

- 取消不能撤回服务器已经收到的请求，供应商仍可能计费。
- 截断检测依赖接口返回标准的完成原因；不提供该标志的兼容接口无法完全确认是否截断。
- 摘要完整性仍取决于来源提供的数据；翻译不会把 RSS 摘要片段补成全文摘要。
