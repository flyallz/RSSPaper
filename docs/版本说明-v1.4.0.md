# 期刊雷达通用版 v1.4.0

本版整理了 Windows 与 macOS 的代码结构，保留原有工作区、RSS/Atom、
Crossref、arXiv、关键词过滤、摘要展开与双向翻译。

- 两端使用同一份界面和业务代码，平台差异集中在独立模块。
- 将网络接入、解析、工作区编辑、筛选、翻译和存储拆分。
- 保持 schema 1 数据格式及旧译文缓存键，增加配置校验和损坏配置保护。
- 修复修改模型设置时，异步译文归入错误缓存的问题。
- Mac 密钥改为原生钥匙串接口；Windows 继续使用 DPAPI。
- 增加统一回归测试、双平台 CI、冻结程序启动检查和 SHA-256 校验文件。

正式代码签名和 Apple 公证仍需要开发者自己的证书与账户。
