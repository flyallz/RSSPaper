# 教育技术培养方案期刊雷达

核对日期：2026-09-21。以你上传的《教育技术学》培养方案第 11—12 页为准：**必读 10 本＋选读 11 本**。书籍、手册不纳入期刊订阅。

## 先导入这个文件

**edtech-radar.opml** 含 **20 个已通过 XML 与期刊身份检查的 RSS**：9 个出版社／期刊官网源，加上 11 个 CNKI 数据库源，覆盖全部 10 本必读刊及 10 本选读刊。《课程·教材·教法》的 CNKI 源也已按刊名核实。仅 IEEE Transactions on Learning Technologies 尚无本次可验证的稳定 RSS。文件按“必读／选读＋语言”分组；标题保留组别，方便 Zotero 显示。同一期刊只导入一个源，避免重复；《现代远程教育研究》的官网 RSS 仍列为备选。

- **Inoreader 网页版**：设置／Preferences → Import, Export, Backup → OPML Import → 上传文件。菜单名称可能随界面语言变化。[官方说明](https://www.inoreader.com/blog/2014/05/opml-subscriptions.html)
- **Zotero 桌面版**：左上角“新建文献库／Add Library”→“新建订阅／New Feed”→“从 OPML／From OPML”。不要走普通的“文件 → 导入参考文献”。看到需要的论文再选择“保存到我的文献库”。[官方说明](https://www.zotero.org/support/feeds)

本次已检查 OPML 语法、地址去重、RSS 内容及期刊匹配，**尚未在你的 Inoreader／Zotero 账号中实测导入**。CNKI 条目日期通常反映数据库记录／期次，和首次上线时间未必一致；文章链接可能要求机构权限。

## 剩余 1 本与备份方式

IEEE Transactions on Learning Technologies 的 IEEE Xplore RSS 本次返回 HTTP 418；Computer Society 旧源停在 2017 年，未收入 OPML。可在 [IEEE Xplore Content Alerts](https://ieeexplore.ieee.org/alerts/journals-magazines) 登录个人账号、关注该刊；官方帮助确认期刊提醒功能，登录与投递仍需在账号内操作。若想统一在 Inoreader 查看提醒邮件，可用其 Newsletter feeds 功能，依账户套餐配置。[IEEE 帮助](https://ieeexplore.ieee.org/Xplorehelp/personalization-settings/content-alerts)

中文刊的 CNKI RSS 都可读，但每次只返回最近 20 条，不能视为完整档案；数据库更新节奏可能晚于官网。需要周更且不漏文时，建议每月对照期刊官网目录检查一次。《现代远程教育研究》的[官网 RSS](https://xdyjyj.scou.cn/download_upload_file.aspx?file_name=/rss/xdycjyyj/cn/current.xml)也可用，但本次更新较 CNKI 慢，留作备份。

## OpenAlex 怎么用

全部 21 个 ISSN 均已查询：10 本英文刊可匹配且有近期记录；中文 3 本匹配但最新实查论文停在 2015—2021 年，另 8 本的 ISSN 查询返回 404。**中文刊以已验证的 CNKI RSS 和官网目录为准，不依赖 OpenAlex 补齐新文。** 核对表含每刊 ISSN、查询链接、匹配 ID、最新实查日期及论文查询入口。

OpenAlex 返回 JSON，不能直接填进 OPML。要将它变成订阅源，需另设定时转换服务并托管 RSS/Atom，本包未部署该服务。少量匿名查询本次可用；长期运行建议使用自己的免费 API key，遵循实时额度。[官方认证说明](https://help.openalex.org/api/authentication/)

## 每周使用的边界

建议每天让阅读器刷新，每周一查看新增条目；RSS 通常只保留最近一批，首次导入的文章不全是本周发表。ScienceDirect 有未来卷期日期，部分源按出刊而非首次上线更新，因此不能只筛“出版日期在过去 7 天”。保留首次发现时间，以 DOI／原文链接去重，每月对照官方目录补漏。

本包只交付订阅入口与说明，**不等于已开通每周推送**，也未核实原 ChatGPT 对话中的自动任务是否实际运行。邮件验证、网页监控、摘要推送和 OpenAlex 转换服务需要分别配置。
