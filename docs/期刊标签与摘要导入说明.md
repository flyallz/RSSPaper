# 期刊标签与摘要导入

Windows 和 Mac 使用同一流程。

## 配置 easyScholar

1. 打开“应用设置”，向下滚动到“期刊标签”。
2. 勾选“启用 easyScholar 期刊 / 会议标签”，填写自己的 easyScholar Secret Key。不要填翻译 API 的密钥，也不要将密钥发送到聊天或提交仓库。
3. 选择需要显示的体系，点击“测试期刊接口”（查询 Nature），再保存设置。
4. 在论文卡片点击“期刊标签”，核对正式期刊或会议全名，再点“查询 / 更新”。标签和详情会保存在本机。

来源名称可以是自己的别名，如 CE 或 AI；正式刊名是另外的字段，可以在“编辑来源”填写。程序可从 Crossref、C&E / 知网的 RSS 或条目元数据读取正式刊名。不能确定时会留空，由用户补充，不拿 arXiv 分类当期刊。预印本只有确认已发表到哪本刊物或哪个会议后才应填写正式名称。

卡片最多显示四项所选标签，悬停可看全部所选标签；“期刊标签”窗口列出接口返回的全部体系。不同体系分别显示，期刊等级来自 easyScholar，并不是程序自己评定。接口没有年度时明确显示“年度未提供 / 接口未提供”，获取日期不等于等级年度。

有效缓存保留七天；无等级结果缓存一天；过期结果不显示在卡片，但详情可查看旧数据并主动更新。缓存最多保留 500 本刊物。失败不会缓存为“无等级”。换密钥或清除密钥会清空等级缓存，防止复用其他账户的自定义目录。请求串行且间隔至少 0.65 秒；取消后不发后续请求。

本版不做全库自动查询。没有密钥或不开启标签，不影响 RSS、翻译、引用和摘要功能。

## 获取摘要

论文卡片上的“获取完整摘要”会尝试 Crossref 元数据和 ScienceDirect / 知网详情页面。网页需要有可识别的题名和摘要区域；题名必须与当前论文匹配，页面提供 DOI 时还会核对 DOI。明显截断的摘要不标为完整；搜索简介、Highlights 和一般网页 description 不作论文摘要。

站点可能要求登录、浏览器验证或动态加载。当前桌面请求不会自动取得 Chrome / Safari 中的校园登录状态，也不会读取整个浏览器 Cookie 库。不能访问时会说明原因，保留已有摘要；不保证每篇自动补全成功。

## 从校园网浏览器或 Zotero 导入

- 浏览器：点击“打开原文”，使用自己的校园网权限或学校代理访问。展开摘要后保存论文网页为 HTML，在对应论文卡片点“导入摘要”，选择该 HTML 文件。当前 HTML 适配支持 ScienceDirect 和知网，保存文件本身必须包含摘要内容。
- Zotero：先通过 Connector 保存论文并确认 Zotero 中有摘要，再导出 CSL JSON。点击“导入摘要”选择 JSON。程序读取 `abstract` 字段，也支持条目 JSON 的 `abstractNote`。某些导出格式或版本不含摘要字段时会明确失败，不从 PDF 或引用信息猜测摘要。
- JSON 必须唯一匹配原始题名，并匹配 DOI 或原文链接；不会按相似题名合并。文献管理器可能保存了摘要片段，所以 JSON 导入内容标记“完整性未确认”，仍可展开、复制和翻译。

导入只更新选中的论文，不导入整个 Zotero 文库、不改变筛选条件。支持文件上限 4 MB；大文库请只导出对应条目。网页和文献 JSON 在本机解析，不发送给 easyScholar；只有用户点击翻译时，摘要才发送给所配置的翻译接口。

## 密钥与关闭行为

Mac 的两个密钥分别保存在独立钥匙串账户；旧翻译密钥账户保持不变。Windows 使用两个独立的当前用户 DPAPI 加密文件。state.json 不保存密钥。密钥输入留空时保留现有值；清除需要勾选对应选项。

正在查询时关闭窗口会取消后续操作，等待当前网络请求退出后关闭；不会强制销毁工作线程。取消不能撤回已经发到服务器的请求。
