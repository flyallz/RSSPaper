# 教育技术期刊雷达 · Mac 桌面小卡片

适用于 **macOS 15 或更新版本的 Apple 芯片 Mac**。解压 `教育技术期刊雷达-Mac.zip`，双击“教育技术期刊雷达.app”打开。窗口可置顶、拖动和缩放；每 30 分钟自动刷新，也可点右上角的刷新图标。按“必读／选读”和“中文／英文”筛选，点击论文标题打开原文。关闭应用后停止刷新。

## 自己管理 RSS

设置中的接口地址、模型名和 API 密钥都支持 Command-V 粘贴；菜单栏也提供“编辑 → 粘贴”。

点右上角的齿轮 →“RSS 订阅”。在左侧选中期刊，可修改名称、RSS 地址、必读/选读和语言属性，点“保存订阅”生效。点“新增”可添加自己的 RSS；选中条目后点“删除”可移除。误删时可点“恢复预置 20 本”，这会用原始列表替换整个当前列表。自定义订阅保存在本机应用支持目录，更新应用不会覆盖；应用自带的 OPML 仅作为初始列表和恢复预置使用。

RSS 地址应为完整的 `https://…` 或 `http://…` 源地址，且返回 RSS 或 Atom 内容。保存后小卡片立即重新抓取。如果某个源暂不可用，状态栏会显示失败数量；可稍后刷新或检查地址。

## 英文标题翻译

点齿轮 →“大模型翻译”，填写**兼容 OpenAI Chat Completions 的完整接口地址**（例如以 `/v1/chat/completions` 结尾）、接口使用的模型名称和 API 密钥，然后开启“启用英文标题中文翻译”并点“保存配置”。本地模型若无需鉴权，密钥可以留空；地址须为 HTTPS，或本机 `http://localhost`、`http://127.0.0.1`。可先点“测试接口”检查连接。

若使用 DeepSeek，接口地址可填写 `https://api.deepseek.com/chat/completions`，模型名称填写 `deepseek-flash`。新版会对该接口关闭思考模式，并在测试失败时显示具体的 HTTP 状态或网络错误；请不要把 API 密钥发给他人。

启用后，卡片只把屏幕中出现的**英文论文标题**发送给你配置的服务；英文原题保留，中文译题显示在下一行。最多同时发起两个翻译请求；结果缓存在本机，同一接口、模型和标题再次出现时不会重复请求。接口可能按调用量收费。API 密钥保存在 macOS 钥匙串，其他配置和译题缓存在本机应用支持目录。翻译失败时可点对应提示重试；未启用时不会发起翻译请求。

## 范围与说明

预置列表覆盖培养方案中有可用 RSS 的 20 本期刊；IEEE Transactions on Learning Technologies 暂无经验证的稳定 RSS，建议在 IEEE Xplore 设置 Content Alerts。CNKI 文章页面可能需要机构访问权限。各期刊 RSS 的发布时间定义不同，列表是源内当前可见的近期论文，并不保证覆盖过去七天全部论文。小卡片与 Inoreader／Zotero 账号独立，不提供系统通知或开机自启。

应用在本机打包并采用临时签名。如 macOS 提示无法验证开发者，可在 Finder 中对应用点右键 →“打开”，按系统提示决定是否运行。
