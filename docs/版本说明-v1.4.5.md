# v1.4.5：复制真实引用

- 将卡片上的“复制出版信息”替换为“复制引用”，所有论文卡片均可打开引用预览。
- 默认 APA 参考文献条目（纯文本）；可选择 BibTeX 或 RIS，后两者适合导入 Zotero / EndNote。
- 使用 DOI 内容协商获取登记元数据和格式化引用，不调用大模型生成作者、年份或页码。仅在 DOI 与当前论文题名核对一致后展示；缺少作者、年份或期刊名称时提示核对。
- 无 DOI 时仅接受 Crossref 中唯一、规范化题名一致的结果；arXiv 官方链接可转换为其登记 DOI。支持用户补充 DOI 后重试。
- 用户查看预览后主动复制。查询失败或取消不修改剪贴板；保存设置、刷新与获取引用不改变卡片阅读位置。
- 引用按论文和格式缓存，来源刷新保留同一论文的有效引用。论文标题、链接或 DOI 改变后不复用旧引用；删除或停用来源后忽略过期查询结果。
- 查询在后台执行；关闭窗口会取消后续请求并等待当前请求退出，避免运行中的线程被销毁。
- Windows 与 Mac 使用同一实现和测试。

## 边界

- APA 输出为参考文献条目，不是正文中的 `(作者, 年份)` 短引文。纯文本复制不保留斜体。
- 登记服务没有该论文、题名无法匹配或服务暂不可用时，不生成猜测引用。可打开原文核对，或从出版社 / Zotero 导出引用。
- 引用服务的格式化结果仍需人工核对，尤其是登记信息缺失、中文姓名或预印本与正式发表版本不同的情况。
- 本版尚未实现网页摘要适配器、Zotero 数据导入及 easyScholar 期刊标签。调研和分阶段方案见《摘要与期刊标签接入方案》。
