Windows 11 / Python 3.12 构建说明
==============================

安装 requirements.txt 后，在本目录运行：
  python -m unittest discover -s tests -v
  python -m PyInstaller --noconfirm --clean JournalRadar.spec

产物位于 dist\JournalRadar\JournalRadar.exe。打包规格文件会排除构建机上可能混入的 Poppler ICU DLL，并将与 PySide6 匹配的 VC 运行库放在程序根目录。请保留整个 dist\JournalRadar 文件夹。

如需验证：
  dist\JournalRadar\JournalRadar.exe --self-test
  dist\JournalRadar\JournalRadar.exe --gui-smoke

运行数据默认位于 %APPDATA%\JournalRadar；测试时可设置 JOURNAL_RADAR_HOME 到单独目录，避免读写个人配置。
