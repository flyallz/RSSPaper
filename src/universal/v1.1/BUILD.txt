Windows 通用版构建入口
====================

当前实现统一在仓库的 src/journal_radar。本目录仅保留兼容启动器和 Windows 打包规格。
请保留完整仓库，不要只复制本目录源码。

从仓库根目录，在 Python 3.12/3.13 虚拟环境中运行：
  python -m pip install -r requirements-build.txt
  python scripts/build-universal.py

脚本运行共享测试、PyInstaller 打包、冻结程序自检和界面启动检查。
产物位于 dist/artifacts，并附 SHA-256 校验文件。
详细说明见 docs/代码架构与维护说明.md。
