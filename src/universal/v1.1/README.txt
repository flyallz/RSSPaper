期刊雷达 · 通用版 v1.4.0（Windows）
================================

解压完整 ZIP，运行 JournalRadar.exe，并保留 _internal 文件夹。
通过新建学科建立工作区，添加 RSS/Atom、Crossref ISSN 或 arXiv 检索来源。
每个来源可设置包含/排除关键词，筛选标题和摘要。

点击刷新来源获取论文；读取失败的原因可在来源管理中查看。
翻译与网络设置中填写完整的 OpenAI Chat Completions 兼容地址、有效模型名和 API 密钥。
标题和摘要分别点击翻译，中文译为英文，其他文本译为中文；成功译文保存在本地缓存。
来源仅给摘要片段时不会自动生成完整摘要；长摘要可展开。

配置保存在 %APPDATA%/JournalRadar，密钥使用当前 Windows 用户 DPAPI 加密。
自动刷新只在程序打开时运行。近 7/30 天筛选只包含精确日期。

v1.4.0 与 Mac 共用一份代码和测试；原工作区及译文缓存保持兼容。
详细说明：https://github.com/flyallz/RSSPaper
程序尚未正式代码签名；翻译可能产生第三方接口费用。
