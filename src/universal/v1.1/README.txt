期刊雷达 · 通用版 v1.2.1（Windows）
================================

这是一款跨学科的期刊论文订阅工具，不预设教育技术期刊。可为不同学科建立独立工作区，并通过期刊 RSS/Atom 地址、ISSN（Crossref）或 arXiv 主题检索添加来源。每个来源还可按标题与摘要设置二层包含/排除关键词。

开始使用
1. 解压整个压缩包，打开 JournalRadar 文件夹中的 JournalRadar.exe。请保留 _internal 文件夹，不要只复制 EXE。
2. 点击“＋ 新建学科”，可建立多个学科工作区。
3. 点击“管理期刊来源”，添加 RSS 地址、期刊 ISSN 或 arXiv 分类/检索式，也可导入 OPML 或旧版教育技术期刊雷达的 feeds.json。
4. 点击“刷新来源”。期刊网站或 Crossref 暂时不可访问时，可在“管理期刊来源”查看每个来源的错误。

自动刷新
“翻译与网络设置”→“自动刷新间隔”可设置 5–1440 分钟，默认 30 分钟；设为“关闭自动刷新”后，仅在手动点击“刷新来源”时刷新（添加或修改来源后也会立即刷新一次）。自动刷新只在程序打开时运行，不会创建后台常驻服务。

论文日期
优先读取 RSS/Atom 的日期字段；若 ScienceDirect 只在论文简介中写“Publication date”，也会识别。只有“January 2027”时显示“2027-01（来源仅提供月份）”，不会虚构成 1 月 1 日；“Available online 28 August 2026”则显示精确在线发表日期。Crossref 只给月份或年份时同样保留其原始精度。近 7/30 天筛选只包含有精确日期的论文；要查看仅有期刊月份的论文，请选择“全部时间”。如果来源确实没有日期，仍会显示“日期未提供”。升级后点击“刷新来源”即可更新原有缓存，不影响已经保存的标题翻译。

翻译与 DeepSeek
英文论文标题不会自动翻译。仅点击该论文的“译为中文”按钮时才调用接口，并缓存成功的译文。
在“翻译与网络设置”里填写：
- 翻译接口完整地址：https://api.deepseek.com/chat/completions
- 模型名称：deepseek-flash
- API 密钥：你的 DeepSeek API 密钥
然后点击“测试翻译”和“保存设置”。这里需要完整的 /chat/completions 地址，不能只填 https://api.deepseek.com。旧版的密钥不会自动复制到通用版；请在通用版中重新填写。密钥以当前 Windows 用户加密方式保存在本机。请勿把 API 密钥写入 OPML、feeds.json 或发给他人。

网络与数据
RSS 的可用性取决于期刊网站；ISSN 来源使用 Crossref 公共元数据接口。若使用 VPN/代理且连接失败，可在“翻译与网络设置”中填写代理地址，例如 http://127.0.0.1:7890。代理会同时用于论文来源和翻译接口。未设置代理时使用 Windows/Python 的系统代理环境设置。
本版数据默认保存在 %APPDATA%\JournalRadar，旧版 %APPDATA%\EdTechRadar 不会被修改。每个学科的期刊与论文分别存储；翻译配置为本应用共用。论文结果会保留原文标题。

说明
本程序未签名，首次启动 Windows 可能出现安全提示。仅从你信任的位置运行。程序不自带任何 API 密钥，翻译请求可能产生第三方服务费用。
